# Changelog

## 1.3.0

The original monolithic prototype was replaced.

- Added separate layout, preference, prediction, personalisation, clipboard, profile and keyboard-surface components.
- Added adaptive field layouts and Enter actions.
- Added long press, key previews, repeat deletion, cursor gestures and word deletion gestures.
- Added ranked offline suggestions, autocorrection, next-word prediction and local learning.
- Added English variants and Nigerian Pidgin starter vocabulary.
- Added clipboard, editing and emoji panels.
- Added terminal, coding and spreadsheet profiles.
- Added one-handed and compact modes.
- Added a complete settings screen and privacy controls.
- Improved accessibility metadata and touch target sizing.
